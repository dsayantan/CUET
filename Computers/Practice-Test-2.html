Question 1Exception Handling
What is the output of the following Python code?
def f(x):
    try:
        print('T', end='')
        y = 10 // x
    except ZeroDivisionError:
        print('Z', end='')
        return 0
    else:
        print('E', end='')
        return y
    finally:
        print('F', end='')

r = f(0) + f(5)
print(r)
  1. TZFTEF0
  2. TZTE2F
  3. TZFTEF2
  4. TZTEF2
Concept to recallelse runs only when the try block raised nothing; finally runs every time – even when the except/else block executes a return. The value being returned is held and handed back after finally finishes.
  1. f(0): prints T; 10 // 0 raises ZeroDivisionError → prints Z; return 0 is pending, so finally prints F first. Returns 0.
  2. f(5): prints T; y = 2, no exception → else prints E; return 2 is pending, finally prints F. Returns 2.
  3. r = 0 + 2 = 2, printed last on the same line ⇒ TZFTEF2.

Answer: option (3) — TZFTEF2

TrapA return does not skip finally; and else is skipped for f(0) only.

Question 4File Handling
What does the following code print?
f = open("marks.txt", "w")
f.write("Asha 82\nRavi 67\nMona 91\n")
f.close()
tot = 0
f = open("marks.txt")
for line in f:
    name, m = line.split()
    if int(m) > 70:
        tot += int(m)
f.close()
print(tot, name)
  1. TypeError
  2. 173 Mona
  3. 240 Mona
  4. NameError
Concept to recallLooping for line in f gives the file one line at a time, each ending in \n. split() with no argument splits on whitespace and drops the \n. Everything read from a text file is a string, so numbers need int().
  1. Line 1 "Asha 82\n" → name = "Asha", m = "82"; 82 > 70 ⇒ tot = 82.
  2. Line 2 "Ravi 67\n": 67 is not > 70, tot unchanged.
  3. Line 3 "Mona 91\n": tot = 82 + 91 = 173.
  4. After the loop name still holds its last value, "Mona" ⇒ 173 Mona.

Answer: option (2) — 173 Mona

Trap240 adds every mark, ignoring the condition. A loop variable survives the loop in Python, so there is no NameError; and int(m) converts the string before comparing, so there is no TypeError.
Question 5File Handling
What is printed by the following code?
with open("poem.txt", "w") as f:
    f.write("To be\nor not\nTo Be\n")
cnt = 0
with open("poem.txt") as f:
    for line in f:
        if line.startswith("To"):
            cnt += line.lower().count("be")
print(cnt, f.closed)
  1. 1 True
  2. 2 False
  3. 1 False
  4. 2 True
Concept to recallA file opened in a with statement is closed automatically when the block ends, so f.closed is True afterwards. String methods such as startswith() and count() are case-sensitive; lower() removes the difference.
  1. Lines: "To be\n", "or not\n", "To Be\n".
  2. "To be": starts with "To"; lower() → "to be" contains "be" once ⇒ cnt = 1.
  3. "or not" does not start with "To" – skipped.
  4. "To Be": lower() → "to be" ⇒ cnt = 2.
  5. The print runs after the with block has closed the file ⇒ 2 True.

Answer: option (4) — 2 True

TrapWithout the lower() call "Be" would not match "be" (giving 1); and leaving a with block closes the file even though close() is never written.
Question 6File Handling

  2. 3
  3. 6

Question 8Stack
The values 1, 2 and 3 are pushed onto an empty stack in this order; a POP may be carried out at any moment in between, and every popped value is printed. Which of the following output sequences is impossible?
  1. 2 3 1
  2. 3 1 2
  3. 3 2 1
  4. 1 2 3
Concept to recallOnly the top element can be popped (LIFO). Once a value has been popped, every value pushed before it and still inside the stack must come out in the reverse of the order it went in.
  1. 1 2 3: push 1, pop; push 2, pop; push 3, pop – possible.
  2. 2 3 1: push 1, push 2, pop 2; push 3, pop 3; pop 1 – possible.
  3. 3 2 1: push all three, then pop three times – possible.
  4. 3 1 2: to print 3 first, 1 and 2 must already be in the stack with 2 above 1, so the next pop must give 2, not 1 – impossible.

Answer: option (2) — 3 1 2

Trap3 2 1 looks the most “reversed”, but it is the natural push-all, pop-all order.

Question 10Stack
Evaluate the postfix expression using a stack:
5 9 3 / 4 * + 6 2 - -
  1. 13
  2. 19
  3. 21
  4. 5
Concept to recallPostfix evaluation: push operands; on an operator pop two – the first popped is the right operand – apply, push the result. The single value left is the answer.
  1. 5 9 3 → [5, 9, 3]; /: 9 / 3 = 3 → [5, 3].
  2. 4 → [5, 3, 4]; *: 3 × 4 = 12 → [5, 12]; +: 17 → [17].
  3. 6 2 → [17, 6, 2]; -: 6 − 2 = 4 → [17, 4]; -: 17 − 4 = 13.

Answer: option (1) — 13

TrapTake the operands the wrong way round at the inner minus (2 − 6 = −4) and you get 17 − (−4) = 21.
Question 11Stack
Convert the infix expression A + B * (C - D) / E to postfix using the stack method.
  1. A B + C D - * E /
  2. A B C D - * + E /
  3. A B C D - * E / +
  4. A B C D - E / * +
Concept to recallOperands go straight to the output. An operator first pops every stacked operator of equal or higher precedence (left-to-right associativity), then is pushed. ‘(’ is pushed; ‘)’ pops back to the matching ‘(’.
  1. A → out; + pushed; B → out; * (higher than +) pushed; ( pushed.
  2. C, D → out; - is pushed above the (. Then ) pops - ⇒ out = A B C D -.
  3. / arrives: top is * (equal precedence) ⇒ pop * first, then push / ⇒ out = A B C D - *.
  4. E → out; end: pop / then + ⇒ A B C D - * E / +.

Answer: option (3) — A B C D - * E / +

TrapA B C D - E / * + treats / as if it bound tighter than the * already waiting – * and / are equal, so the left one leaves first.

Question 20Sorting

Question 22Understanding Data
The number of books issued from a library on five days is 4, 8, 6, 5, 7 (mean 6, standard deviation about 1.41). If every value is increased by 10, what happens to the mean and the standard deviation?
  1. The mean becomes 16; the standard deviation stays about 1.41
  2. Both the mean and the standard deviation increase by 10
  3. The mean stays 6; the standard deviation becomes about 11.41
  4. The mean becomes 16; the standard deviation becomes about 14.1
Concept to recallAdding a constant to every value shifts the mean by that constant but leaves every deviation (x − x̄) unchanged, so the standard deviation (a measure of spread) does not change. Multiplying every value by k multiplies the standard deviation by k.
  1. New values 14, 18, 16, 15, 17 ⇒ mean = 80 / 5 = 16.
  2. Deviations from 16: −2, 2, 0, −1, 1 – exactly the old deviations.
  3. So the variance is still 10 / 5 = 2 and σ = √2 ≈ 1.41.

Answer: option (1) — The mean becomes 16; the standard deviation stays about 1.41

Trap14.1 treats “add 10” as “multiply by 10”; the spread of the data has not changed.
