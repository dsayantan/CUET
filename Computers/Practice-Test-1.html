Question 1Exception Handling
In Python, the else block attached to a try statement is executed:
  1. only when an exception is raised in the try block
  2. only when no exception is raised in the try block
  3. every time, whether or not an exception is raised
  4. only when the except block itself raises an exception
Concept to recalltry → except (runs on an exception) → else (runs only if the try block finished without an exception) → finally (runs always).
  1. except runs when an exception occurs; finally runs in every case.
  2. else is the “no exception” branch: it runs only when the try block completes normally.

Answer: option (2) — only when no exception is raised in the try block

Trap“Every time” describes finally, not else.
Question 2Exception Handling
Which built-in exception is raised when the following statement is executed?
total = "5" + 5
  1. ValueError
  2. NameError
  3. TypeError
  4. SyntaxError
Concept to recallTypeError: an operation is applied to an object of an unsuitable type. ValueError: right type, unsuitable value (e.g. int("5a")). NameError: an undefined name.
  1. The statement is syntactically valid and every name is defined.
  2. + cannot add a str and an int – the operand types are incompatible ⇒ TypeError.

Answer: option (3) — TypeError

TrapValueError is for a correct type with a bad value, such as int("five").
Question 3Exception Handling
What is the output of the following code?
def div(a, b):
    try:
        r = a // b
    except ZeroDivisionError:
        print("Z", end="")
        r = -1
    else:
        print("E", end="")
    finally:
        print("F", end="")
    return r

print(div(7, 2), div(3, 0))
  1. 3 -1EFZF
  2. EF3 ZF-1
  3. EFZF3 -1
  4. EZF3 -1
Concept to recallArguments of print() are evaluated before print outputs anything. finally runs after either the else branch or the except branch.
  1. div(7, 2): no exception ⇒ else prints E, finally prints F, returns 3.
  2. div(3, 0): ZeroDivisionError ⇒ except prints Z, sets r = −1, finally prints F.
  3. Both calls finish before the outer print runs, so “EFZF” appears first, then the outer print writes 3 -1: EFZF3 -1.

Answer: option (3) — EFZF3 -1

TrapInterleaving each return value with its own letters – the outer print has not started yet.
Question 4File Handling
A file log.txt already exists. Which mode opens it for both reading and writing, keeps its existing contents, places the file pointer at the beginning, and raises an error if the file does not exist?
  1. 'w+'
  2. 'a+'
  3. 'rb'
  4. 'r+'
Concept to recall'r+' read + write, pointer at start, file must exist. 'w+' read + write but truncates (creates if absent). 'a+' read + append, pointer at the end, creates if absent.
  1. 'w+' wipes the existing contents – ruled out.
  2. 'a+' keeps the contents but starts at the end and creates a missing file – ruled out.
  3. 'rb' is read-only binary.
  4. 'r+' meets every condition.

Answer: option (4) — 'r+'

Trap'a+' also reads and writes without erasing – but its pointer is at the end.

Question 6File Handling

f = open("notes.txt")

  1. alp beta 2
  2. alp ha 2
  3. alp ha 3
  4. alpha beta 1
Concept to recallEvery read method continues from where the previous one stopped. readline() reads up to and including the next \n; readlines() returns all remaining lines as a list.

  2. readline() finishes that line → “ha\n”, stripped to “ha”.

  4. Output: alp ha 2.

Answer: option (2) — alp ha 2

TrapAssuming readline() starts a fresh line – it resumes from the pointer, so it returns the rest of “alpha”.

Question 8Stack
An attempt to perform a POP operation on an empty stack results in a condition called:
  1. Overflow
  2. Underflow
  3. Collision
  4. Deadlock
Concept to recallOverflow: PUSH on a full stack. Underflow: POP (or PEEK) on an empty stack. Collision belongs to hashing.
  1. There is nothing to remove, so the stack underflows.

Answer: option (2) — Underflow

Question 9Stack
What is the postfix form of the infix expression A * (B + C) / D?
  1. A B C + * D /
  2. A B C * + D /
  3. A B + C * D /
  4. A B C D + * /
Concept to recallInfix → postfix: operands keep their order; an operator is written after its two operands. * and / have equal precedence and associate left to right.
  1. Brackets first: (B + C) → B C +.
  2. A * (B + C) → A B C + *.
  3. Then divide by D: A B C + * D /.

Answer: option (1) — A B C + * D /

Trap“A B C D + * /” divides first – it means A * ((B + C) / D), a different order.
Question 10Stack
Evaluate the postfix expression using a stack: 6 2 3 + * 4 -
  1. 20
  2. 11
  3. 26
  4. 14
Concept to recallPostfix evaluation: push operands; on an operator pop two (first popped = right operand), apply, push the result. The single value left is the answer.
  1. Push 6, 2, 3. +: pop 3, 2 → push 5. Stack: 6, 5.
  2. *: pop 5, 6 → push 30.
  3. Push 4. -: pop 4, 30 → 30 − 4 = 26.

Answer: option (3) — 26

TrapPopping the operands in the wrong order for - gives 4 − 30.
Question 11Stack
What is the output of the following code?
s = []
for ch in "STACK":
    s.append(ch)
out = ""
while len(s) > 2:
    out += s.pop()

  1. KCA ['S', 'T']
  2. STA ['C', 'K']
  3. KCAT ['S']
  4. ACK ['S', 'T']
Concept to recallA list used as a stack: append() pushes at the end (top) and pop() removes from the same end – so items come out in reverse order.
  1. After the loop s = [S, T, A, C, K] with K on top.
  2. Pop while more than 2 remain: K, C, A ⇒ out = “KCA”.
  3. The loop stops with s = [‘S’, ‘T’].

Answer: option (1) — KCA ['S', 'T']

Question 13Queue

q = []

    q.append(x)

Concept to recallQueue on a list: enqueue = append() at the rear; dequeue = pop(0) from the front. q[0] is the front, q[-1] the rear.

  2. pop(0) removes the front 5 → [10, 15].

Question 16Searching
Binary search is applied to the sorted list [3, 8, 12, 19, 25, 31, 40, 47, 52] to find the key 47, with mid = (first + last) // 2. How many comparisons with list elements are needed?
  1. 2
  2. 4
  3. 3
  4. 5
Concept to recallBinary search compares the key with the middle element; if the key is larger, search the right half (first = mid + 1), if smaller the left half (last = mid − 1).
  1. first 0, last 8 ⇒ mid 4, element 25 < 47 ⇒ first = 5.
  2. mid (5 + 8)//2 = 6, element 40 < 47 ⇒ first = 7.
  3. mid (7 + 8)//2 = 7, element 47 = key ⇒ found. 3 comparisons.

Answer: option (3) — 3

Question 17Searching
What is the maximum number of comparisons binary search needs to decide whether a key is present in a sorted list of 100 elements?
  1. 50
  2. 10
  3. 6
  4. 7
Concept to recallEach comparison halves the search area, so the worst case is ⌊log2 n⌋ + 1 comparisons.
  1. 26 = 64 < 100 < 128 = 27 ⇒ ⌊log2 100⌋ = 6.
  2. Worst case = 6 + 1 = 7 comparisons.

Answer: option (4) — 7

TrapUsing ⌊log2 n⌋ alone (6) misses the final comparison.
Question 18Searching
The keys 23, 47, 33, 90, 57, 16 are placed in a hash table of size 10 using the hash function h(key) = key % 10. Which indices receive more than one key (i.e. where do collisions occur)?
  1. 3 and 7
  2. 3 and 6
  3. 0 and 7
  4. 6 and 7
Concept to recallRemainder method: index = key mod table size. Two keys mapping to the same index is a collision; a hash function with none is a perfect hash function.
  1. 23 → 3, 47 → 7, 33 → 3, 90 → 0, 57 → 7, 16 → 6.
  2. Index 3 gets 23 and 33; index 7 gets 47 and 57 ⇒ collisions at 3 and 7.

Question 19Sorting
Selection sort (ascending) is applied to [29, 10, 14, 37, 13]. What is the list after the second pass?
  1. [10, 13, 14, 29, 37]
  2. [10, 29, 14, 37, 13]
  3. [10, 14, 29, 37, 13]
  4. [10, 13, 14, 37, 29]
Concept to recallSelection sort: in pass i find the smallest element of the unsorted part and swap it with the first unsorted position. One swap per pass.
  1. Pass 1: minimum 10 swaps with 29 → [10, 29, 14, 37, 13].
  2. Pass 2: minimum of [29, 14, 37, 13] is 13, swaps with 29 → [10, 13, 14, 37, 29].

Answer: option (4) — [10, 13, 14, 37, 29]

TrapThe fully sorted list is what you get after all four passes, not two.
Question 20Sorting
Insertion sort (ascending) is applied to [50, 20, 40, 10, 30]. What is the list after the third pass? (Pass k inserts the element at index k into the sorted part on its left.)

  1. Pass 1 inserts 20 → [20, 50, 40, 10, 30].
  2. Pass 2 inserts 40 → [20, 40, 50, 10, 30].

Question 21Sorting
How many swaps does bubble sort make to sort [5, 1, 4, 2, 8] in ascending order?
  1. 4
  2. 3
  3. 5
  4. 6
Concept to recallBubble sort swaps only adjacent out-of-order pairs, and each swap removes exactly one inversion (a pair i < j with a[i] > a[j]). Total swaps = number of inversions.
  1. Inversions: (5, 1), (5, 4), (5, 2), (4, 2). 8 is larger than all, 1 smaller than all after it.
  2. Total 4 swaps (pass 1 makes 3: [1, 4, 2, 5, 8]; pass 2 makes 1: [1, 2, 4, 5, 8]).

Answer: option (1) — 4

Question 24Understanding Data
The daily number of absentees in a class over four days was 4, 8, 6, 2. What is the standard deviation (rounded to two decimals)?
  1. 5.00
  2. 2.58
  3. 1.58
  4. 2.24
Concept to recallStandard deviation (NCERT): σ = √( Σ(x − x̄)2 / n ), the positive square root of the variance.
  1. Mean = 20/4 = 5.

Answer: option (4) — 2.24

Question 30Database Concepts
Which of the following statements about a foreign key are correct?

  2. (B) and (C) only
  3. (A), (B) and (D) only
