ConceptNames, objects and mutability

  • Mutable: list, dict, set — can be changed in place. Immutable: int, float, str, tuple, bool.
  • b = a does not copy a list: both names point to the same object, so a change through b shows in a. Use a[:] or list(a) to copy.
  • Slicing s[start:stop:step]: stop is excluded, a negative step walks backwards, s[::-1] reverses.
  • Python was created by Guido van Rossum (1991). Logical operators are the words and, or, not.

ConceptDefining and calling

  • def name(params): defines a function; return sends back a value (otherwise None).
  • Default parameters must come after all non-default ones: def f(a, b=2) is fine, but def f(a=1, b) is a SyntaxError.
  • At the call, positional arguments come before keyword ones. f(y=5, 30) is a SyntaxError.
  • A name assigned inside a function is local unless it is declared global.

ConceptErrors and exceptions

  • Syntax error (parsing error): the rules of the language are broken, for example a missing colon. The program does not start at all.
  • Exception: a runtime error in a syntactically correct program. It is a Python object that represents the error.
  • Built-in exceptions are raised by the interpreter. A programmer can raise one with raise, or test a condition with assert expr, msg, which raises AssertionError if the expression is false.
  • Handling: code that may fail goes in try; except clauses catch named exceptions (a single try may have several); else runs only if nothing was raised; finally always runs.
  • What happens when an error occurs (NCERT order): the error is encountered → an exception object is created → the exception is raised (thrown) to the runtime system → the runtime searches the call stack in reverse order for a handler → the handler executes (the exception is caught); if no handler is found, the program terminates.

ConceptText and binary files

  • Text file: characters, with each line ending in an EOL character (\n). Binary file: raw bytes such as images or pickled Python objects; it is not human-readable.
  • f = open(filename, mode) returns a file object (or file handle); f.close() flushes the data and frees the file. with open(...) as f: closes the file automatically, even if an exception occurs.
  • File-object attributes: f.name, f.mode, f.closed. (tell is a method, not an attribute.)
  • Writing: write(str) returns the number of characters written; writelines(list_of_str) writes several strings and does not add newlines.
  • Reading: read(n) returns n characters, or everything if n is omitted; readline() returns one line, including its \n; readlines() returns a list of strings, one per line.
  • Random access: tell() gives the current byte position as an integer; seek(offset, ref) moves the pointer, where ref is 0 = from the beginning (the default), 1 = from the current position, 2 = from the end.
  • pickle (binary files): pickle.dump(obj, f) pickles an object, turning it into a byte stream (serialisation); pickle.load(f) unpickles one object. Reading past the last object raises EOFError, which is handled with try/except EOFError.

TrapsTraps the distractors use

  • "rw" is not a mode (CUET has asked this three times). The read-and-write mode is r+.
  • ab is valid, but it is a binary mode, so it is “invalid for a text file”.
  • readlines() returns a list, not a string. writelines adds no newline. There is no writeline().
  • Offset at the end of the file: a and a+ only. w, w+, r+ and wb+ start at the beginning.

  • pickle at end of file raises EOFError. Neither IOError nor “EOF” alone is right. Pickling needs binary mode, and open(...).dump is not a thing.

ConceptStack: last in, first out

  • A stack is a linear, ordered list in which insertion and deletion happen at one end only, called the TOP. This makes it LIFO: last in, first out.
  • PUSH adds at the top and POP removes from the top. Overflow means pushing onto a full stack; underflow means popping from an empty stack. A check such as if len(stack) == 0 guards against underflow.
  • In Python a list is a stack whose top is the end of the list: append() pushes and pop() pops. A Python list grows as needed, so overflow does not occur in practice.
  • NCERT’s helper functions are isEmpty, opPush, opPop, top (peek without removing), size and display.
  • Applications: reversing a string, undo/redo in an editor, the browser back button, matching parentheses, function calls, and converting and evaluating expressions. Real-life stacks include a pile of plates, bangles on a wrist, a stack of chairs or books.
  • Notations: infix A + B; prefix or Polish + A B (operator before operands); postfix or reverse Polish A B + (operator after operands). Postfix and prefix need no brackets, and one left-to-right scan evaluates a postfix expression.

TrapsTraps the distractors use

  • The distractor “FIFO” belongs to a queue. A stack is LIFO and has one open end.
  • Popping from an empty stack is underflow, not overflow. if len(Stack)==0: print("error") is an underflow check.
  • M items pushed and M/2 popped onto a stack of size N leaves M/2 items. The size N is a red herring.
  • For A^B^C^D the prefix is ^A^B^CD, because ^ is right-associative. Converting it as if it were left-associative gives ^^^ABCD, which is wrong.
  • In postfix evaluation the first value popped is the right operand. Getting this backwards changes the answer for − and /.
  • A printer queue, “standing in a line for ration” and asynchronous data transfer are applications of a queue, not a stack.

ConceptQueue and deque

  • A queue is an ordered linear list with two ends: insert at the REAR (ENQUEUE) and delete at the FRONT (DEQUEUE). It is FIFO: first in, first out, or first come, first served.
  • NCERT’s helper functions are enqueue, dequeue, isEmpty (call it before a dequeue to avoid underflow), isFull (before an enqueue, to avoid overflow), peek (read the front without removing it) and size.
  • In Python, a list is a queue with append() at the rear and pop(0) at the front. Either end of the list could be chosen as the front, but the choice must stay fixed.
  • An array-based linear queue of size LIMIT is full when rear = LIMIT − 1.
  • A deque (double-ended queue, pronounced “deck”) allows insertion and deletion at both ends: insertFront, insertRear, deletionFront, deletionRear. It can act as a stack (use one end) or as a queue (insert at one end, delete at the other). Python provides it in the collections module.
  • Queue applications: a printer shared by many users, an IVRS or call-centre waiting line, a web server taking many requests, CPU job scheduling (the jobs wait in a queue), and a ticket counter. Deque applications: checking palindromes, browser history with a size limit, and undo lists that drop their oldest entry.

ConceptThree ways to search

  • Linear (sequential, serial) search compares the key with each element in turn. It works on an unsorted list. Best case: 1 comparison (the key is first). Worst case: n (the key is last or absent). Order O(n). It is the right choice for a small or unsorted list.
  • Binary search needs a list sorted in ascending or descending order. It compares the key with the middle element, mid = (first + last) // 2, and keeps only the half that can still hold the key. For an ascending list: first = mid + 1 if the middle value is smaller than the key, last = mid - 1 if it is larger (the two are swapped for a descending list). The search area halves after every pass, so it needs at most ⌊log2n⌋ + 1 comparisons: O(log n). Best case 1 comparison. Typical uses: a dictionary or telephone directory, database indexes and routing tables. CUET 2024 also counted “finding the minimum or maximum of a sorted list” as an application.
  • Hashing computes the position directly: a hash function such as the remainder method h(k) = k % (table size) gives the index in a hash table, so a search takes one comparison whatever the size of the list. Two keys that map to the same slot cause a collision, and placing the second one elsewhere is collision resolution. If every key maps to a different slot the function is a perfect hash function, and only then can no collision occur. The table may be larger than the list.
  • The efficiency of an algorithm is measured by time and space.

ConceptBubble, selection and insertion sort

  • Bubble sort compares adjacent elements and swaps them if they are out of order. After pass k the k largest elements sit in their final places at the right end. It needs n − 1 passes, and pass i makes n − i comparisons.
  • Selection sort selects the smallest element of the unsorted part and swaps it with the leftmost unsorted element, which then joins the sorted part. In the i-th pass the minimum goes to position i. It needs n − 1 passes and makes at most one swap per pass.
  • Insertion sort takes the next element and inserts it into its place in the sorted part on the left, swapping it leftwards past every larger neighbour. Its passes run from the 2nd element to the n-th: n − 1 passes. The total number of swaps equals the number of out-of-order pairs in the list.
  • Time complexity (the time an algorithm takes as the input grows): no loop → constant, O(1); a single loop → linear, O(n); a nested loop → quadratic, O(n2). When an algorithm has both, the nested loop decides. All three sorts are O(n2) in the worst case. The extra time spent sorting a large list is called overhead.
  • One run through the list is a pass.

ConceptWhy a DBMS, and its vocabulary

  • Limitations of a file system: difficulty of access, data redundancy (the same data in many files), data inconsistency (copies that do not match), data isolation (data scattered across files in different formats), data dependence (changing a file’s structure means changing every program that uses it), and no controlled data sharing.
  • A DBMS (MySQL, Oracle, PostgreSQL, SQL Server, MS Access) removes these problems. Its own limitations are increased complexity, cost, and the risk that a single failure affects everyone. MS Excel is a spreadsheet, not a DBMS.
  • Database schema: the design or structure of the database (its tables, attributes, types and constraints). Data constraint: a restriction on the values a column may take, such as NOT NULL or UNIQUE. Meta-data (the data dictionary): data about data, the schema plus its constraints, kept in the database catalog. Database instance: a snapshot of the data at a given moment. Query: a request for information.
  • Relational model: a relation is a table; an attribute is a column; a tuple is a row; the domain is the set of values an attribute may take; degree = the number of attributes (columns); cardinality = the number of tuples (rows).
  • Properties of a relation: each attribute has a unique name; the order of attributes does not matter; tuples are distinct; the order of tuples does not matter; all values in a column come from the same domain; each value is atomic; NULL marks an unknown value.
  • Keys: a candidate key is any attribute or set that uniquely identifies tuples; the primary key is the one candidate chosen by the designer (unique and NOT NULL); the others are alternate keys; a composite key uses two or more attributes (BookID + Issued_date); a foreign key is an attribute that refers to the primary key of another relation. TrapsTraps the distractors use

  • Degree = columns and cardinality = rows. The swapped definition is the commonest distractor.
  • A primary key can never be NULL or repeat (it is UNIQUE + NOT NULL). Of the keys, the foreign key is the one that may repeat and may hold NULL; an ordinary non-key column may do both too.
  • Data consistency, data independence and storage space are not limitations of a file system; inconsistency, dependence, redundancy and isolation are.
  • Selection gives a horizontal subset (rows); projection gives a vertical one (columns).
  • “The design of a database” is its schema; “a snapshot at a moment” is an instance; the synonym for meta-data is the data dictionary.
  • If a student with Rno 14 has two sports in one table, the student’s details are repeated: data redundancy.

ConceptCommands and clauses

  • DDL (data definition): CREATE DATABASE/TABLE, ALTER TABLE, DROP TABLE/DATABASE, TRUNCATE. DML (data manipulation): INSERT, UPDATE, DELETE, and the query SELECT. Also: USE db;, SHOW TABLES;, DESC table; (the structure of a table).
  • Data types: CHAR(n) is fixed length (use it for a one-letter grade: CHAR(1)); VARCHAR(n) is variable length; INT, FLOAT, DATE as 'YYYY-MM-DD'.
  • Constraints: NOT NULL, UNIQUE, DEFAULT (the value used when none is supplied), PRIMARY KEY (= NOT NULL + UNIQUE), FOREIGN KEY. ALTER TABLE ... ADD PRIMARY KEY(col) works only if the column already holds no NULL and no repeated value; NCERT puts it as “the column must be NOT NULL”.
  • ALTER TABLE: ADD col type, ADD PRIMARY KEY(col), ADD FOREIGN KEY(col) REFERENCES T(col), MODIFY col newtype, DROP col, DROP PRIMARY KEY.
  • DROP TABLE deletes the table and its structure; TRUNCATE removes every row but keeps the structure; DELETE removes the rows that match its WHERE clause (all rows if there is none).
  • SELECT: DISTINCT removes repeated rows; WHERE filters rows with = <> > < >= <=, AND OR NOT, BETWEEN a AND b (both ends included), IN (...), LIKE and IS NULL / IS NOT NULL. ORDER BY sorts, ascending by default.
  • LIKE wildcards: % matches any number of characters, including none; _ matches exactly one. '%S' means ends in S; '_o%' means o is the second letter.
  • NULL is an unknown value: any arithmetic with NULL gives NULL, and the test is IS NULL, never = NULL.
  • Single-row (scalar) functions return one value per row. Multiple-row (aggregate) functions — MAX, MIN, SUM, AVG, COUNT — return one value per group and ignore NULLs, except COUNT(*), which counts every row.
  • GROUP BY puts rows with equal values into groups; HAVING filters the groups and may use aggregates; WHERE filters rows before grouping and may not use aggregates.
  • Joins: listing two tables in FROM with no condition gives the Cartesian product. An equi-join adds WHERE A.key = B.key. A natural join is an equi-join that shows the common column only once. Joining N tables needs N − 1 join conditions. If both tables have a column of the same name, qualify it as Table.column.

ConceptNetworks and their types

  • A computer network is two or more computing devices interconnected to share data and resources. The Internet is the global network of such devices. Milestones in order: ARPANET connects UCLA and SRI (1969); Ray Tomlinson’s e-mail, with @ for “at” (1971); TCP/IP becomes ARPANET’s standard (1983); Tim Berners-Lee at CERN creates HTML, URL and HTTP, which give birth to the WWW (1990).
  • By area covered: LAN (a room, building or campus, up to about 1 km) < MAN (a city: a cable TV network) < WAN (a country or the world: the Internet). The 2026 syllabus names only these three; NCERT and the older papers also have the PAN (about 10 m: a phone tethered to a laptop by USB or Bluetooth), the smallest of all.
  • Addresses. The MAC address is the physical, permanent address burnt into the NIC: 48 bits, written as 12 hexadecimal digits in six pairs. The first 24 bits (6 hex digits) are the manufacturer’s OUI (Organisational Unique Identifier); the last 24 bits are the card’s serial number. The IP address is logical and can change from network to network. IPv4 has 32 bits, written as four decimal numbers from 0 to 255 (e.g. 192.168.0.178); IPv6 has 128 bits.
  • Web vocabulary. WWW: the web of linked pages, reached through the Internet. HTML: the language used to design web pages. URL (Uniform Resource Locator): the full address of a resource; the domain name is the server’s part of it. HTTP: the rules for retrieving linked pages. A web server is the hardware and software that answer a browser’s requests. A web browser is Chrome, Firefox or Safari (Wikipedia is a website). A cookie is a small text file that a site leaves with the browser.
  • Internet versus web (a syllabus line): the Internet is the network of networks, the hardware and the connections; the WWW is one service that runs on it. E-mail and file transfer (FTP) also use the Internet, but they are not the Web.
  • DNS (Domain Name System) maps domain names to IP addresses; the lookup is called domain name resolution, and a DNS server keeps the domain names and their IP addresses.

Worked exampleCase study: wire up a campus

A company has four blocks with A: 25 computers, B: 120 computers, C: 40 computers, D: 10 computers. Distances: A–B 60 m, B–C 120 m, B–D 50 m, A–C 170 m, A–D 90 m, C–D 140 m.   2. (b) A star centred on B: A–B 60 + B–C 120 + B–D 50 = 230 m. This is also the shortest way to join all four blocks: every other layout is longer (the next best, B–D, A–B, C–D, is 250 m).

  5. (e) A LAN: all four blocks are within one site. Linking to a branch in another city would make a WAN.
  6. (f) A firewall at the gateway. For video conferencing with a head office the answer is a WAN link such as a satellite or leased line.

TrapsTraps the distractors use

  • A hub broadcasts; a switch sends only to the selected device. A switch is what filters data before forwarding it.
  • Repeaters regenerate signals; routers choose routes; gateways convert protocols. The device that handles “protocol conversion” is the gateway.
  • In a star, one computer failing leaves the rest working; the central device failing stops all of them.
  • MAC is permanent, 48-bit and on the NIC. The IP address is the one that can change, and the ISP assigns it, not the MAC.
  • “Ring” is a topology, not a device; “circle” is not a topology; “assembler” is not a network device.

ConceptData communication

  • Components: sender, receiver, message, communication medium, and protocols. A compiler has no part in it.
  • Capacity: bandwidth is the range of frequencies a channel can carry, measured in hertz. Data transfer rate is the number of bits sent per second: bps, Kbps, Mbps, Gbps, with 1 Kbps = 210 bps, 1 Mbps = 220 bps and 1 Gbps = 230 bps = 1024 Mbps.
  • Switching: circuit switching reserves one path for the whole session, as the old telephone network did. Packet switching splits the data into numbered packets that travel independently and are reassembled at the end; the Internet uses it.
  • Guided (wired) media: twisted pair (cheapest; telephone lines and LANs, with an RJ-45 connector), coaxial (cable TV), optical fibre (light pulses, highest bandwidth, immune to electrical noise, costly). Unguided (wireless): radio waves, microwaves (line of sight), infrared (short range: remote controls). Wi-Fi and Bluetooth use radio; WiMax (Worldwide Interoperability for Microwave Access) is long-range broadband.
  • Mobile telecommunication (a syllabus line): 1G analog voice (1980s); 2G digital voice plus SMS (GSM, CDMA); 3G mobile Internet and video calls; 4G all-IP broadband (LTE); 5G very high data rates and very low delay, for devices and machines as well as people.
  • Protocols: HTTP (web pages), HTTPS (HTTP encrypted with SSL/TLS; the site needs an SSL digital certificate), FTP (file transfer, even between systems with different directory structures), SMTP (sending e-mail), POP3 (receiving e-mail), TCP/IP (the Internet’s packet protocol), PPP (point-to-point link).
