ConceptReflexive, symmetric, transitive — tested on the pairs

  • Reflexive on A: (a, a) ∈ R for every a ∈ A. One missing loop kills it.
  • Symmetric: (a, b) ∈ R ⇒ (b, a) ∈ R. Check each off-diagonal pair has its mirror.
  • Transitive: (a, b), (b, c) ∈ R ⇒ (a, c) ∈ R. Hunt for a chain a→b→c whose short-cut is missing. A relation with no chains at all (e.g. {(1, 2)}) is transitive vacuously.
  • Equivalence = all three. Its classes partition A; an equivalence relation is fixed by a partition.
  • Rules that are always equivalences: “a − b divisible by n”, “a + b even”, “same school / same age”, “lines parallel” (counting a line as parallel to itself), “triangles similar/congruent”. “a ≤ b” is reflexive and transitive but not symmetric; “L1 ⊥ L2” is symmetric only.
Hold on to this: Draw the arrow diagram: loops for reflexive, two-way arrows for symmetric, short-cuts for transitive.

ConceptOne-one and onto

  • One-one (injective): f(x1) = f(x2) ⇒ x1 = x2. A strictly monotonic function is one-one; an even function (x2, |x|, cos x) on ℝ is not.
  • Onto (surjective): range = codomain. Compute the range and compare with the stated codomain — x2 + x + 1 on ℕ never hits 1 or 2, so it is not onto ℕ.
  • Bijective = both; exactly the invertible functions. For finite A, B with |A| = |B|, one-one ⇔ onto.
  • Composition: (g∘f)(x) = g(f(x)) — apply f first. Domain of log(x2 − 4) needs x2 > 4.

DerivationWhy there are 2n(n−1) reflexive relations

A × A has n2 ordered pairs. A reflexive relation must contain the n diagonal pairs, so only the other n2 − n pairs are free, each in or out.

  1. Pairs available: n2; forced in: n; free: n2 − n = n(n − 1).
  2. Each free pair: 2 choices ⇒ 2n(n−1) reflexive relations. For n = 3 that is 26 = 64.
  3. Same idea for symmetric: the n diagonal pairs are free, and the n(n − 1)/2 mirror pairs {(a, b), (b, a)} go in or out together ⇒ 2n + n(n−1)/2 = 2n(n+1)/2.

TrapsTraps

  • Reflexive needs (a, a) for every a in A, not only those that appear in R.

ConceptInverse of an inverse: when does sin−1(sin θ) = θ?

  • Only when θ lies in the principal range: sin−1(sin θ) = θ for θ ∈ [−π/2, π/2], cos−1(cos θ) = θ for θ ∈ [0, π], tan−1(tan θ) = θ for θ ∈ (−π/2, π/2).
  • Otherwise rewrite the angle first: sin(2π/3) = sin(π/3), so sin−1(sin 2π/3) = π/3; cos(13π/6) = cos(π/6) ⇒ cos−1(cos 13π/6) = π/6.
  • The other order is always fine inside the domain: sin(sin−1x) = x for x ∈ [−1, 1].
  • Negative arguments: sin−1, tan−1, cosec−1 are odd (pull the minus out); cos−1(−x) = π − cos−1x, likewise sec−1 and cot−1.

ConceptTypes, orders and transposes

  • Am×nBp×q exists iff n = p; the product is m × q. AB and BA both exist iff B is n × m.
  • Symmetric: AT = A. Skew-symmetric: AT = −A ⇒ every diagonal entry is 0 (aii = −aii).
  • Every square A = ½(A + AT) + ½(A − AT): symmetric part + skew part.
  • For symmetric A, B: AB − BA is skew, AB + BA symmetric; AB is symmetric only if AB = BA.
  • Odd powers of a skew matrix are skew, even powers symmetric.
  • Diagonal ⊃ scalar ⊃ identity: a scalar matrix is diagonal with all diagonal entries equal; identity is scalar with 1s.
  • Number of m × n matrices with entries from a k-element set: kmn (2×2 with 0/1 entries: 24 = 16).

  • Idempotent A2 = A ⇒ Ak = A for every k ≥ 1, so expand by the binomial theorem treating A like a number with Ak → A. (I + A)n = I + (2n − 1)A.
  • Involutory A2 = I ⇒ even powers are I, odd powers are A.
  • Cayley–Hamilton for 2 × 2: A2 − (tr A)A + |A| I = O. So in “A2 − kA + λI = O” read k = trace, λ = determinant.
  • A−1 from the identity: A2 − 3A − 7I = O ⇒ A − 3I = 7A−1 ⇒ A−1 = (A − 3I)/7.
  • Rotation R(θ) = cosθ−sinθsinθcosθ: R(α)R(β) = R(α + β), R(θ)n = R(nθ), RTR = I.

  1. Start from A(adj A) = |A| In.

ConceptProperties that make a determinant vanish

  • Two equal (or proportional) rows/columns ⇒ 0. After C1 → C1 + C2 + C3, a column of a + b + c, b + c + a, … becomes proportional to a column of 1s.
  • Adding a multiple of one row to another leaves the value unchanged; swapping two rows changes the sign.
  • A common factor of a row comes out. A determinant that is a polynomial in x vanishing when x = a has (x − a) as a factor.
  • Split a column that is a sum: |x  x2  1 + x3| = |x  x2  1| + |x  x2  x3| = (1 + xyz)(y − x)(z − x)(z − y) — so it vanishes for distinct x, y, z only if xyz = −1.

ConceptIncreasing, decreasing and extrema from one sign chart

  • f′ > 0 on an interval ⇒ f strictly increasing there; f′ < 0 ⇒ strictly decreasing.
  • Critical points: f′(c) = 0 or f′ undefined. Factorise f′ and mark its zeros on a number line.
  • First-derivative test: f′ changes + to − at c ⇒ local max; − to + ⇒ local min; no change (x3 at 0) ⇒ neither (a point of inflection).
  • Second-derivative test: f′(c) = 0 and f″(c) < 0 ⇒ max, f″(c) > 0 ⇒ min; f″(c) = 0 is inconclusive.
  • Absolute extremes on [a, b]: compare f at the critical points inside and at a and b.
  • “Increasing for all x”: need f′(x) ≥ 0 for every x (e.g. x3 − kx needs 3x2 − k ≥ 0 ∀x ⇒ k ≤ 0).

ConceptCorner-point method

  • The feasible region of linear constraints is always convex; it may be bounded, unbounded or empty (infeasible).
  • If an optimum exists, it occurs at a corner point. Bounded region ⇒ both max and min exist.
  • Unbounded: the corner value M is the max only if the open half-plane Z > M has no point in common with the region (for a min, the half-plane Z < m). Otherwise there is no max (min).
  • If Z is optimal at two adjacent corners, it is optimal at every point of the edge joining them (infinitely many solutions).
  • A corner is found by solving its two boundary lines together; a point that violates any constraint is not a corner.
  • Test a half-plane with the origin: 2x + 4y ≤ 9 holds at (0, 0), so it is the closed half-plane containing O; > or < gives an open half-plane (the line excluded).

ConceptConditional probability and independence

  • P(A|B) = P(A ∩ B)/P(B); multiplication rule P(A ∩ B) = P(B)P(A|B).
  • Independent ⇔ P(A ∩ B) = P(A)P(B) ⇔ P(A|B) = P(A). Then A′, B′ are independent too.
  • Independent is not mutually exclusive: two events with positive probability cannot be both.
  • At least one of independent A1, …, An: 1 − ΠP(Ai′). None: ΠP(Ai′).
  • Exactly one of A, B: P(A) + P(B) − 2P(A ∩ B). Two witnesses contradict: P(A)P(B′) + P(A′)P(B).
  • Reduced sample space: “given the black die shows 5” leaves 6 outcomes; count inside them.

ConceptTotal probability and Bayes

  • E1, …, En mutually exclusive and exhaustive: P(A) = ΣP(Ei)P(A|Ei).
  • Bayes: P(Ei|A) = P(Ei)P(A|Ei) / ΣjP(Ej)P(A|Ej) — one branch over the sum of branches.
  • Recognise it: “a ball drawn is red; find the probability it came from bag II” — the question asks backwards along the tree.

DerivationBayes’ theorem in two lines

It is only the definition of conditional probability used twice.

  1. P(Ei|A) = P(Ei ∩ A)/P(A) = P(Ei)P(A|Ei)/P(A).
  2. The Ej split A into disjoint pieces: P(A) = ΣP(A ∩ Ej) = ΣP(Ej)P(A|Ej).
  3. Substitute. On the tree: numerator = one red leaf, denominator = all red leaves.

TrapsTraps

  • Independent ≠ mutually exclusive.
  • P(A|B) and P(B|A) are different: divide by the probability of the event you are given.
  • In a table with k2 terms (2k2, 7k2 + k), reject the root that makes some probability negative.
  • “Without replacement”: the second draw is out of one fewer ball; and P(second is red) = P(first is red) by symmetry.
  • Bayes denominators add all branches that end in the observed event.
