Question 1Relations and Functions
Let A = {1, 2, 3} and R = {(1, 1), (2, 2), (3, 3), (1, 2), (2, 3)} be a relation on A. Which of the following statements are correct?
(A) R is reflexive
(B) R is symmetric
(C) R is transitive
(D) R is antisymmetric, i.e. (a, b) ∈ R and (b, a) ∈ R ⇒ a = b
Choose the correct answer from the options given below:
  1. (A), (C) and (D) only
  2. (A) and (D) only
  3. (A) only
  4. (A), (B) and (D) only
Concept to recallReflexive: every (a, a) present. Symmetric: each pair reversed present. Transitive: (a, b), (b, c) ⇒ (a, c).
  1. (1, 1), (2, 2), (3, 3) all belong to R, so R is reflexive: (A) true.
  2. (1, 2) ∈ R but (2, 1) ∉ R: not symmetric, (B) false.
  3. (1, 2) and (2, 3) are in R but (1, 3) is not: not transitive, (C) false.
  4. No two distinct elements are related both ways, so R is antisymmetric: (D) true.

Answer: option (2) — (A) and (D) only

TrapChecking transitivity only on the diagonal pairs makes (C) look true; the chain 1 → 2 → 3 is what breaks it.
Question 2Relations and Functions
The function f : ℝ → ℝ defined by f(x) = x|x| is
  1. one-one but not onto
  2. onto but not one-one
  3. neither one-one nor onto
  4. one-one and onto
Concept to recallWrite a modulus function piecewise; a strictly increasing continuous function whose limits are ±∞ is a bijection of ℝ.
  1. f(x) = x2 for x ≥ 0 and −x2 for x < 0.
  2. Both pieces are increasing and they join at 0, so f is strictly increasing: one-one.
  3. Non-negative outputs come from x = √y; negative y from x = −√(−y): onto.

Answer: option (4) — one-one and onto

TrapTreating x|x| like x2 (which repeats values and misses negatives) gives “neither”.
Question 3Inverse Trigonometric Functions
The principal value of cos−1(cos 7π6) is
  1. 5π6
  2. 7π6
  3. π6
  4. −5π6
Concept to recallPrincipal range of cos−1 is [0, π]; cos−1(cos θ) = θ only for θ in that range.
  1. 7π/6 lies outside [0, π].
  2. cos(7π/6) = cos(2π − 7π/6) = cos(5π/6), and 5π/6 ∈ [0, π].

Answer: option (1) — 5π6

Trap7π/6 cancels the functions without checking the range; −5π/6 has the right cosine but lies outside [0, π]; π/6 is the reference angle with the sign of the cosine dropped.

Question 11Determinants
The system x + y + z = 6, x + 2y + 3z = 10, x + 2y + λz = μ has infinitely many solutions if
  1. λ = 3, μ ≠ 10
  2. λ ≠ 3, μ = 10
  3. λ = 3, μ = 10
  4. λ = 10, μ = 3
Concept to recallUnique solution iff det ≠ 0. When det = 0, compare the equations: same left side and same right side ⇒ infinitely many; same left side, different right side ⇒ none.
  1. Coefficient determinant = λ − 3 (R3 − R2 leaves (0, 0, λ − 3)).
  2. For non-uniqueness, λ = 3; then equations 2 and 3 have the same left side.
  3. They agree, giving infinitely many solutions, only if μ = 10.

Answer: option (3) — λ = 3, μ = 10

Trapλ = 3, μ ≠ 10 is the condition for no solution; λ ≠ 3 always gives a unique solution.

Question 15Continuity and Differentiability
If y = xsin x, x > 0, then the value of dydx at x = π2 is
  1. 0
  2. 1
  3. 2π
  4. π2
Concept to recallVariable base and variable power: take logs, then differentiate implicitly.
  1. log y = sin x log x ⇒ 1ydydx = cos x log x + sin xx.
  2. At x = π/2: y = π/2, cos x = 0, sin x = 1.
  3. dydx = π2 · 2π = 1.

Answer: option (2) — 1

Trap0 differentiates as if the base were constant (only the cos x log x term survives); 2/π stops at (1/y)dy/dx without multiplying by y; π/2 is the value of y itself.

Question 17Continuity and Differentiability
For f(x) = |x − 2| + |x|, x ∈ ℝ, which of the following statements are correct?
(A) f is continuous everywhere
(B) f is differentiable at x = 1
(C) f is not differentiable at x = 0 and at x = 2
(D) f′(3) = 2
Choose the correct answer from the options given below:
  1. (A) and (C) only
  2. (A), (C) and (D) only
  3. (A), (B), (C) and (D)
  4. (A), (B) and (C) only
Concept to recallA sum of moduli is continuous everywhere; it can fail to be differentiable only where an argument is zero.
  1. f(x) = 2 − 2x (x < 0), 2 (0 ≤ x ≤ 2), 2x − 2 (x > 2).
  2. Continuous everywhere: (A) true. Constant near x = 1, so f′(1) = 0: (B) true.
  3. Slopes −2 | 0 at x = 0 and 0 | 2 at x = 2 differ: (C) true.
  4. For x > 2, f′(x) = 2: (D) true.

Answer: option (3) — (A), (B), (C) and (D)

TrapBelieving a modulus function is non-differentiable everywhere in its middle range rejects (B); it is flat there.

Question 19Application of Derivatives
Case study: an open box from a square sheet (Questions 19–21)

A craft teacher has a square sheet of cardboard of side 18 cm. From each corner she cuts out an equal square of side x cm and folds up the flaps to make an open box (no lid). The volume of the box is V(x) cm3, where 0 < x < 9.

The volume V(x) of the box is an increasing function of x on the interval
  1. (3, 9)
  2. (0, 3)
  3. (0, 9)
  4. (0, 4.5)
Concept to recallV increases where V′(x) > 0. Factor V′ before reading its sign.
  1. V(x) = x(18 − 2x)2.
  2. V′(x) = (18 − 2x)2 − 4x(18 − 2x) = (18 − 2x)(18 − 6x) = 12(9 − x)(3 − x).

Answer: option (2) — (0, 3)

Trap(0, 4.5) halves the domain by guesswork; (3, 9) reads the sign of (3 − x) the wrong way round.

Question 22Application of Derivatives
