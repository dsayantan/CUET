Question 1Relations and Functions
The number of equivalence relations on the set A = {1, 2, 3, 4} which contain the ordered pair (1, 2) is
  1. 15
  2. 2
  3. 5
  4. 4
Concept to recallAn equivalence relation on a finite set is the same thing as a partition of it into classes. Containing (1, 2) means 1 and 2 lie in the same class.
  1. Glue 1 and 2 into one block {1, 2}; now partition the three objects {1, 2}, 3, 4.
  2. Partitions: {12}{3}{4}, {123}{4}, {124}{3}, {12}{34}, {1234} — five in all.
  3. Each partition is exactly one equivalence relation, so the count is 5.

Answer: option (3) — 5

Trap15 counts all equivalence relations on a 4-element set (the condition is ignored); 4 forgets the universal relation {1234}; 2 counts only the smallest and the universal relation.
Question 2Relations and Functions
Consider the following statements about functions from R to R:
  1. (A) f(x) = 2x + sin x is one-one.
  2. (B) g(x) = |x| + x is onto.
  3. (C) h(x) = x3 + x is a bijection.
  4. (D) k(x) = x1 + |x| is onto.
Choose the correct answer from the options given below:
  1. (A), (C) and (D) only
  2. (A) and (C) only
  3. (A), (B) and (C) only
  4. (C) only
Concept to recallOne-one: a derivative of one sign throughout (strictly monotonic) is enough. Onto R: the range must be all of R — check limits at ±∞ and any lower or upper bound.
  1. (A) f′(x) = 2 + cos x ≥ 1 > 0: strictly increasing, so one-one. True.
  2. (B) g(x) = 2x for x ≥ 0 and 0 for x < 0: never negative, so not onto. False.
  3. (C) h′(x) = 3x2 + 1 > 0 and h → ±∞: one-one and onto. True.
  4. (D) |k(x)| < 1 always: range is (−1, 1), not R. False.
  5. True: (A) and (C) only.

Answer: option (2) — (A) and (C) only

TrapTaking k as onto because it is increasing adds (D); an increasing function can still have a bounded range. Rejecting (A) because sin x oscillates forgets that 2x dominates it.
Question 3Inverse Trigonometric Functions
The value of cos−1(cos 5π4) + sin−1(sin 3π5) is
  1. 23π20
  2. 37π20
  3. 27π20
  4. 33π20
Concept to recallcos−1(cos θ) = θ only for θ ∈ [0, π]; sin−1(sin θ) = θ only for θ ∈ [−π/2, π/2]. Otherwise bring θ into the principal range first.
  1. cos(5π/4) = cos(2π − 5π/4) = cos(3π/4), and 3π/4 ∈ [0, π]: the first term is 3π/4.
  2. sin(3π/5) = sin(π − 3π/5) = sin(2π/5), and 2π/5 ∈ [−π/2, π/2]: the second term is 2π/5.
  3. Sum = 15π/20 + 8π/20 = 23π/20.

Answer: option (1) — 23π20

Trap37π/20 cancels both functions blindly; 27π/20 fixes only the cosine; 33π/20 fixes only the sine.
Question 4Inverse Trigonometric Functions

Question 8Matrices
Let A and B be square matrices of the same order. Consider the statements
  1. (A) (AB)T = BTAT.
  2. (B) If A and B are symmetric, then AB is always symmetric.
  3. (C) Every square matrix can be written uniquely as the sum of a symmetric and a skew-symmetric matrix.
  4. (D) If A2 = I, then (A + I)2 = 2(A + I).
Choose the correct answer from the options given below:
  1. (A), (C) and (D) only
  2. (A), (B), (C) and (D)
  3. (A) and (C) only
  4. (A), (B) and (C) only
Concept to recall(AB)T = BTAT; for symmetric A, B, AB is symmetric iff AB = BA; A = ½(A + AT) + ½(A − AT); I commutes with everything.
  1. (A) is the reversal law. True.
  2. (B) (AB)T = BTAT = BA, which equals AB only when they commute. False.
  3. (C) True, and the split ½(A + AT) + ½(A − AT) is unique.
  4. (D) (A + I)2 = A2 + 2A + I = I + 2A + I = 2(A + I). True.

Answer: option (1) — (A), (C) and (D) only

TrapExpanding (A + I)2 as A2 + I (dropping the middle term 2A) wrongly rejects (D); assuming products of symmetric matrices are symmetric wrongly accepts (B).
Question 9Determinants
A is a square matrix of order 3 with |A| = 5. Then |adj(2A)| is equal to
  1. 200
  2. 1600
  3. 400
  4. 25
Concept to recall|adj M| = |M|n−1 and |kM| = kn|M| for an n × n matrix.
  1. |2A| = 23·5 = 40.
  2. |adj(2A)| = |2A|2 = 1600.

Answer: option (2) — 1600

Question 10Determinants
If the points (1, 2), (3, k) and (5, 8) are collinear, then k is
  1. 3
  2. −5
  3. 5
  4. 10
Concept to recallThree points are collinear iff the “area determinant” det[[x1, y1, 1], [x2, y2, 1], [x3, y3, 1]] is 0.
  1. Along row 1: 1(k − 8) − 2(3 − 5) + 1(24 − 5k) = 20 − 4k.
  2. 20 − 4k = 0 ⇒ k = 5. (Check: the slopes (5 − 2)/2 and (8 − 5)/2 agree.)

Answer: option (3) — 5

TrapDropping the minus sign on the middle cofactor gives 12 − 4k and k = 3; halving only one term (20 − 2k) gives 10.
Question 11Determinants
The system of equations kx + y + z = 1, x + ky + z = 1, x + y + kz = 1 has no solution when k is
  1. −2
  2. 1
  3. 1 or −2
  4. 2
Concept to recall|A| ≠ 0: unique solution. |A| = 0: inconsistent if (adj A)B ≠ O, otherwise infinitely many (check by substituting).
  1. |A| = (k − 1)2(k + 2), so trouble only at k = 1 or −2.
  2. k = 1: all three equations are x + y + z = 1: infinitely many solutions.
  3. k = −2: adding the three equations gives 0 = 3: no solution.

Answer: option (1) — −2

TrapAnswering every root of |A| = 0 includes k = 1, where the system is consistent with infinitely many solutions; 2 is the sign slip in the factor k + 2.

Question 13Determinants
The roots of the equation x231x132x = 0 are
  1. −1, −3, 4
  2. 1, −3, 4
  3. 1, 3, 4
  4. 1, 3, −4
Concept to recallExpand, then test small integers (factor theorem); the sum of the roots of a monic cubic with no x2 term is 0.
  1. Along row 1: x(x2 − 2) − 2(x − 3) + 3(2 − 3x) = x3 − 13x + 12.
  2. x = 1 gives 0, so (x − 1) is a factor: x3 − 13x + 12 = (x − 1)(x2 + x − 12) = (x − 1)(x − 3)(x + 4).
  3. Roots 1, 3, −4 (sum 0, as it must be).

Answer: option (4) — 1, 3, −4

TrapA sign slip in the middle cofactor −2(x − 3) changes the constant term and flips roots; the roots must add to 0, which eliminates two options at once.

Question 15Continuity and Differentiability
The function f(x) = {x2 + ax + b,0 ≤ x < 23x + 2,2 ≤ x ≤ 42ax + 5b,4 < x ≤ 8 is continuous on [0, 8]. Then
  1. a = 3, b = −2
  2. a = −3, b = 2
  3. a = 3, b = 2
  4. a = 2, b = 0
Concept to recallEach piece is a polynomial, so only the joins can fail: match the one-sided limits at x = 2 and x = 4.
  1. At x = 2: 4 + 2a + b = 3(2) + 2 = 8 ⇒ 2a + b = 4.
  2. At x = 4: 3(4) + 2 = 14 = 8a + 5b.
  3. Substitute b = 4 − 2a: 8a + 20 − 10a = 14 ⇒ a = 3, b = −2.

Answer: option (1) — a = 3, b = −2

TrapUsing only the first join leaves a one-parameter family; a = 2, b = 0 satisfies the first equation but not the second. Finding a = 3 and then slipping the sign in b = 4 − 2a gives a = 3, b = 2.

Question 19Application of Derivatives
The volume of a spherical balloon increases at the rate of 36π cm3/s. The rate at which its surface area increases when the radius is 3 cm is
  1. 12π cm2/s
  2. 36π cm2/s
  3. 24π cm2/s
  4. 72π cm2/s
Concept to recallChain two rates through dr/dt: dV/dt = 4πr2dr/dt and dS/dt = 8πrdr/dt.
  1. 36π = 4π(9)dr/dt ⇒ dr/dt = 1 cm/s.
  2. dS/dt = 8π(3)(1) = 24π cm2/s. (Shortcut: dS/dt = (2/r)dV/dt.)

Answer: option (3) — 24π cm2/s

Trap12π differentiates 4πr2 as 4πr; 36π copies the volume rate; 72π takes dV/dr = 4πr and gets dr/dt = 3.
Question 20Application of Derivatives

Question 21Application of Derivatives

  1. 16π cm2
  2. 8π cm2
  3. 40π cm2
  4. 24π cm2
Concept to recallUse the fixed quantity to eliminate one variable: πr2h = 16π gives h = 16/r2; then minimise S(r) = 2πr2 + 2πrh.
  1. S(r) = 2πr2 + 32π/r.
  2. S′ = 4πr − 32π/r2 = 0 ⇒ r3 = 8 ⇒ r = 2, h = 4 (height = diameter).

Trap16π is the curved surface alone and 8π the two ends alone; solving r2 = 16 instead of r3 = 8 gives r = 4 and 40π.
Question 22Application of Derivatives
The function f(x) = x3 + ax2 + 3x + 5 is increasing on R if and only if
  1. −3 < a < 3
  2. −3 ≤ a ≤ 3
  3. −9 ≤ a ≤ 9
  4. a ≤ −3 or a ≥ 3
Concept to recallA quadratic px2 + qx + r with p > 0 is ≥ 0 for all x iff its discriminant ≤ 0. A derivative vanishing at a single point does not stop f increasing.
  1. f′(x) = 3x2 + 2ax + 3 must be ≥ 0 for all x.
  2. Discriminant 4a2 − 36 ≤ 0 ⇒ a2 ≤ 9 ⇒ −3 ≤ a ≤ 3.
  3. At a = 3, f′ = 3(x + 1)2 vanishes only at x = −1; indeed f(x) = (x + 1)3 + 4 (and at a = −3, (x − 1)3 + 6), which is even strictly increasing. So the end-points belong to the answer whichever NCERT definition (increasing or strictly increasing) is used.

Answer: option (2) — −3 ≤ a ≤ 3

TrapDropping the end-points forgets that f′ may vanish at an isolated point; −9 to 9 reads a2 ≤ 9 as |a| ≤ 9, forgetting the square root; the outside interval is where f′ changes sign.
