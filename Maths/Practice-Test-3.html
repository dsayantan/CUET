Question 1Relations and Functions
Let A = {1, 2, 3} and B = {a, b, c, d}. The number of one-one functions from A to B is
  1. 64
  2. 24
  3. 81
  4. 4
Concept to recallOne-one functions from an m-set into an n-set (m ≤ n): nPm = n(n − 1)…(n − m + 1). All functions: nm.
  1. 1 can go to any of 4 images, 2 to any of the remaining 3, 3 to any of the remaining 2.
  2. Number = 4 × 3 × 2 = 4P3 = 24.

Answer: option (2) — 24

Trap64 = 43 counts all functions; 81 = 34 counts functions from B to A; 4 = 4C3 chooses the images but forgets to arrange them.
Question 2Relations and Functions
Which of the following statements are correct?
(A) The relation R = {(a, b) : a − b is divisible by 3} on ℤ is an equivalence relation.
(B) The relation “is perpendicular to” on the set of lines in a plane is symmetric but not transitive.
(C) f : ℕ → ℕ, f(x) = 2x is onto.
(D) f : ℝ → ℝ, f(x) = x3 is a bijection.
Choose the correct answer from the options given below:
  1. (A), (C) and (D) only
  2. (A) and (B) only
  3. (A), (B), (C) and (D)
  4. (A), (B) and (D) only
Concept to recallOnto means every element of the co-domain is an image. A strictly increasing function on ℝ with range ℝ is a bijection.
  1. (A) a − a = 0; if 3 | (a − b) then 3 | (b − a); and 3 | (a − b), 3 | (b − c) give 3 | (a − c). True.
  2. (B) L ⊥ M ⇒ M ⊥ L, but L ⊥ M, M ⊥ N makes L ∥ N. True.
  3. (C) Odd numbers such as 3 have no pre-image under 2x in ℕ. False.
  4. (D) x3 is strictly increasing (one-one) and every real k = (k1/3)3 (onto). True.

Answer: option (4) — (A), (B) and (D) only

Trap2x is one-one but not onto ℕ — ticking (C) is the slip. Leaving out (D) comes from treating x3 like x2, which is not one-one.

  3. 0
  4. π

  1. 4 × 2
  2. 3 × 3
  3. 2 × 4
  4. not defined
Concept to recall(m × n)(n × p) = m × p; the transpose of an m × n matrix is n × m.

Question 7Matrices
For square matrices A and B of the same order, which of the following statements are correct?
(A) (AB)T = BTAT
(B) Every diagonal element of a skew-symmetric matrix is zero
(C) A + AT is skew-symmetric
(D) AB = BA always
(E) AAT is symmetric
Choose the correct answer from the options given below:
  1. (A), (B) and (C) only
  2. (A), (B) and (E) only
  3. (A), (D) and (E) only
  4. (B), (C) and (E) only
Concept to recall(A + AT)T = A + AT, (AAT)T = AAT; aii = −aii forces aii = 0.

  2. (B) aii = −aii ⇒ aii = 0: true.
  3. (C) (A + AT)T = AT + A, so it is symmetric: false.

Question 18Continuity and Differentiability

  2. (A) and (B) only
  3. (A), (B) and (C) only
  4. (A) and (D) only
